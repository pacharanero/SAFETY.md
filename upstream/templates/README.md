# Upstream template renderings

This folder contains first-pass text renderings of upstream clinical safety templates stored in [`resources/templates/`](../../resources/templates/).

These files are not SAFETY.md-native templates. They are source material for designing a new, modern template set.

| File | Upstream document | Status |
|---|---|---|
| [`clinical-risk-management-plan-template.md`](./clinical-risk-management-plan-template.md) | Clinical Risk Management Plan template | First-pass extraction; provenance incomplete. |
| [`clinical-risk-management-system-template.md`](./clinical-risk-management-system-template.md) | Clinical Risk Management System template | First-pass extraction; provenance incomplete. |
| [`clinical-safety-case-report-template.md`](./clinical-safety-case-report-template.md) | Clinical Safety Case Report template | First-pass extraction; provenance incomplete. |

Spreadsheet templates are currently retained as binaries with provenance records only. See [`../../queries.md`](../../queries.md) for the open question about CSV/Markdown rendering.
