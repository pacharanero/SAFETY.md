# SAFETY.md Router

Use when the user asks which SAFETY.md skill to run.

## Route

- Create or update a CSMF/file set: `safety-md-csmf`
- Identify hazards: `safety-md-hazard-workshop`
- Review existing safety docs: `safety-md-review`
- Check DUAA2025/information-standard implications: `safety-md-duaa2025-check`
- Migrate old docs/templates: `safety-md-template-modernise`
- Triage medical-device uncertainty: `safety-md-mdr-triage`
- Prepare DTAC clinical safety evidence: `safety-md-dtac-evidence`

## Completion criterion

Recommend one skill, explain why in one sentence, and list the minimum inputs needed.
