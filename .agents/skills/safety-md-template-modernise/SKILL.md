# SAFETY.md Template Modernise

Use only when explicitly asked to modernise or migrate existing clinical safety documentation.

## Steps

1. Inventory existing safety documents, templates, generated files, and provenance. Completion: source material list is complete.
2. Identify real safety decisions vs boilerplate/sediment. Completion: preserve list and discard list are explicit.
3. Flag stale project-specific references and old organisation names. Completion: deliberate attribution is separated from accidental hangover text.
4. Map existing content to SAFETY.md file set. Completion: migration plan exists.
5. Apply safe migrations or draft patches. Completion: unknowns go to `queries.md`.

## Never do

- Do not delete real safety decisions to make docs cleaner.
- Do not remove attribution/licensing text without preserving provenance.
- Do not silently change compliance meaning.

## Completion criteria

- Existing material is mapped to SAFETY.md structure.
- Boilerplate reduction does not erase safety evidence.
- Stale references are flagged or fixed.
- Open questions are recorded.
